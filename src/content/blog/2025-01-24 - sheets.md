### Home Automation
<i class="ti ti-brand-github"></i><i class="ti ti-brand-android"></i><i class="ti ti-device-remote"></i> [Fire TV App Shortcuts](https://github.com/marsdeat/firetv-app-shortcuts) <span role="img" aria-label="CC0"><i class="ti ti-creative-commons-zero"></i><i class="ti ti-no-creative-commons"></i></span> _(Active)_ A repository for compiling information about ABD commands, remote keycodes, and application package names for my Fire TV (2024 TCL 55PF650K). Includes look-up tables and code snippets, as well as information on creating shortcuts to open apps. Likely applicable to other TV models, though obviously untested for that purpose.

### Nintendo
<i class="ti ti-table"></i><i class="ti ti-device-nintendo"></i> [Nintendo Sales Data](https://marsde.at/NintendoSales) <span role="img" aria-label="Creative Commons Attribution"><i class="ti ti-creative-commons"></i><i class="ti ti-creative-commons-by"></i></span> _(Active)_ A table compiling Nintendo console and software sales. Up-to-date (or near) for Switch, Wii U, and 3DS. Partial for earlier consoles.

<i class="ti ti-table"></i><i class="ti ti-device-nintendo"></i> [Nintendo Triangle Codes](https://marsde.at/Triangles) <span role="img" aria-label="Creative Commons Attribution"><i class="ti ti-creative-commons"></i><i class="ti ti-creative-commons-by"></i></span> _(Inactive, still maintained)_ Have you ever looked at the spine and/or rear of a game for a Nintendo console and noticed a coloured triangle? Those are region codes, and we've been trying to compile a list of them!

<i class="ti ti-table"></i><i class="ti ti-device-nintendo"></i> [Console Timelines](https://marsde.at/ConsoleTimelines) <span role="img" aria-label="Creative Commons Attribution"><i class="ti ti-creative-commons"></i><i class="ti ti-creative-commons-by"></i></span> _(Inactive, slightly outdated)_ For the Wii U and Nintendo Switch, a timeline of notable first-party events and releases. (Hardware, software, Directs, and financial results)

### Pokémon

<i class="ti ti-brand-apple"></i> [Pokémon GO code card shortcut]() This is very much a me problem, but this is an iOS Shortcut that takes a photo as its input, and automatically detects the code and fills it in on Niantic's redemption website.

<i class="ti ti-brand-mastodon"></i> [Pokémon of the Day](): _(Inactive, Might bring back)_ A very simple Twitter/Mastodon joke bot posting from a restricted list of Pokémon to propogandise about my favourites.
